# Asset Folder Rules

This folder contains project assets only.

Rules:
- Do not copy assets from outside this repository.
- Do not use copyrighted posters, brand logos, screenshots, or third-party visual assets.
- Do not use Netflix logos or brand marks.
- Keep generated assets original.
- Use meaningful file names.
- Use lowercase_with_underscores.
- Optimize image size before committing.
- Register new assets in pubspec.yaml.
- Do not add unused assets.

Expected folders:
- assets/images/
- assets/icons/
- assets/certificates/

Required image assets:
- images/empty_watchlist.png
- images/empty_search.png
- images/error_state.png
- images/poster_placeholder.png
- images/backdrop_placeholder.png

Required icon assets:
- icons/app_icon.png

SSL certificate assets:
- Store certificates only under assets/certificates/.
- Do not rename certificates randomly after they are referenced by code.
